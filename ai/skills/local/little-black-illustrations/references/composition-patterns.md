# Composition patterns and originality rules

## Base structure types

Pick one structure; don't mix too many.

### Workflow

Good for: input → process → output, content production, AI workflows, automation chains.

How to draw: input on the left, Little Black or a weird machine processing in the middle,
output on the right, orange arrows for the main flow.

### System fragment

Good for: information sources, filters, databases, renderers, a slice of an agent system.

How to draw: only 3–5 core modules; Little Black takes part in one key action.

### Before / after

Good for: chaotic/ordered, manual/automatic, scattered/converged, anxious/stable.

How to draw: chaos on the left, stability on the right, an orange arrow between. The
character can be more exaggerated.

### Character state

Good for: user pain points, creator state, too many tools, information anxiety, stuck →
running.

How to draw: 2–4 small states, one short label per state.

### Conceptual metaphor

Good for: content factory, information warehouse, mental black box, workflow machine,
automated daily report.

How to draw: one big weird object or machine, a little input, one output. It should be
memorable.

### Method layering

Good for: methodology frameworks, system hierarchy, capability stack, content-system
layering.

How to draw: boxes stacked layer by layer — not a formal pyramid; Little Black hauling
bricks or building beside it.

### Map / route

Good for: idea → launch, user path, content hand-off path, learning path.

How to draw: one winding path, a few nodes, Little Black leading a line or walking.

### Mini-comic panels

Good for: failure → success, the real process, a rant, before/after use.

How to draw: 2–4 small scenes, each panel expressing only one action.

## Original-metaphor generation method

Reinvent the metaphor from the current article every time; never copy an old image.

### Three steps

1. Swap the abstract concept for a physical action: stuck, dropped, gotten heavier,
   sorted, settled, fermented, opened a door, folded, unpacked, flowed back.
2. Swap the system structure for a low-tech object: a broken machine, cardboard boxes,
   drawers, water pipes, a mailbox, a weird dial, a scale, a well, a ladder, a strange
   workstation.
3. Give Little Black the action: not standing beside it, but stuck inside the machine,
   pulling the wrong line, guarding a gate, hauling, patching, weighing, holding a
   ladder, recording, or stuffing something into some weird device.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water
  pipe, ball of string, sluice gate, turntable, black box, hole punch, pasta press,
  clothesline, weird workstation.
- Use only 1–2 at a time; don't pile them on.

### Little Black action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack,
  mark, recycle.
- The action must serve the core meaning; don't be weird for weirdness's sake.

## Anti-repetition rules

Don't open or reproduce `assets/examples/` by default. Those images are only for style
calibration — line density, white space, color restraint, Little Black's vibe.

Unless the user explicitly says "like this one / reproduce this composition / edit using
this case", do not directly reuse these old compositions:

- Conveyor belt with two break points
- Little Black pulling a judgment lever inside a content machine
- Little Black becoming a funnel sorting traffic/trust/conversion
- Little Black slicing the material fish
- Little Black leading the hand-off path
- Little Black pulling three layers of information sources
- Three Little Blacks each holding a megaphone / building a bridge / opening a door
- Little Black stamping a script toolbox
- Little Black holding a sign watching the common-pitfalls path

Use a fresh metaphor even for similar themes. E.g. a "hand-off path" need not be a route
— it could be Little Black attaching the content's tail to a doorknob;
"one-input-many-uses" need not be a fish — it could be Little Black pressing one paper
ball into several shapes.
