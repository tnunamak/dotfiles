# Artifact Read Order

Use this order for a steering audit artifact stack.

## 1. Index

Purpose: orientation map.

Expected sections:

- read order;
- temporary tools;
- corpus/session facts;
- current best understanding;
- next audit candidates;
- model/tool caveats.

## 2. Rollup

Purpose: best compact answer.

Expected sections:

- classification counts;
- primitives that survived contrast;
- observed / inferred / judgment boundary for each main conclusion;
- weakened hypotheses;
- next measurement controls;
- best answer to "are we going right?"

## 3. Modeling Spikes

Purpose: reasoning and empirical scaffolding.

Expected sections:

- premise and tractability answer;
- candidate modeling frames;
- spike results;
- failed metrics;
- red-team corrections.

## 4. Calibration Cards

Purpose: concrete examples.

Expected sections:

- window or strand;
- target object;
- steering act;
- agent uptake;
- evidence;
- repair/acceptance;
- primitive/counterexample.

## 5. Outcome Verification

Purpose: protect against trusting agent final messages.

Expected sections:

- sampled claims;
- repo evidence;
- runtime evidence if available;
- human acceptance or later repair;
- residual risk.

## 6. UI Or Workbench

Purpose: navigation and intuition.

Use only after the artifact stack exists. A UI should display uncertainty,
contrast classes, primitive counterexamples, and pending controls. It should not
present a fake score or evaluator.
